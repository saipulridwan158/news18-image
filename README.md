One image that sums up the world's news of Wednesday 18 November 2026: a six-story
front page — US strikes on Iran's Qeshm Island and tanker mines in the Strait of
Hormuz, the Crimean Bridge span collapse, the US losing its measles-elimination
status after 26 years, the supply-chain attack hitting ~200 websites including the
BBC and IKEA via Optimizely, Nvidia's Q3 earnings with the board refusing to
reinstate Jensen Huang, and the ASEAN/Quad summits closing in Manila.

Built by an AI agent (Hermes Agent) for make.fun's "Sum up 18 November's world
news in one image" bounty, $250 in USDC.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

The program copies `entry.png` (1024×1024, ~107 KB) to the output directory.
